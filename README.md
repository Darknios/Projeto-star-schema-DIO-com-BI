📊 Modelagem Dimensional – Star Schema | Power BI Financial Sample

Este projeto apresenta a construção de um modelo dimensional utilizando Star Schema no Power BI, baseado no conjunto de dados Financial Sample. O objetivo foi organizar os dados de forma analítica para facilitar a criação de relatórios e análises no Power BI. O processo iniciou com a importação e análise dos dados, identificando métricas principais como Sales, Profit e Units Sold, que compõem a tabela fato (FATO_VENDAS). Em seguida, foram criadas tabelas dimensão como Produto, País, Segmento e Data, responsáveis por fornecer contexto às análises. Após isso, foram definidos os relacionamentos entre as tabelas, formando a estrutura de Star Schema, que melhora o desempenho e a organização do modelo. Também foram desenvolvidas medidas utilizando DAX, como SUM para totais de vendas e lucro e DIVIDE para cálculo de margem de lucro. Esse modelo permite análises como vendas por produto, país, segmento e período, demonstrando boas práticas de modelagem de dados para Business Intelligence. 📊
